## How it works

<Steps>

1. You describe what you want. The agent works out where it fits in your spec, or whether it's new.

2. It asks about the things that matter: numbered questions, lettered options, its recommendation first, or your own answer.

3. It proposes the spec change and plan. You approve it or send it back.

4. It builds, then works through gates. A judgment gate waits for your approval. A mechanical gate clears only on a test run the CLI executed and recorded itself.

5. Each acceptance criterion maps to a test, each approval is hashed against what you approved, and `lyceum check` enforces both in the commit hook and in CI.

</Steps>

The agent can say it's done. Only the CLI can record that it is.

## Works with

| Agent | Tested version | Status |
|---|---|---|
| Claude Code | 2.1.318 | ✅ |
| Codex | 0.164.0 | ✅ |
| OpenCode | 2.0.18 | ✅ |
| Pi | 0.86.0 | ✅ |
| Command Code | 1.88.3 | ✅ |

Each was tested end to end in the v1 release check. `lyceum init` finds the agents you use and installs the skills, slash commands and a hook for each.

<Aside>
Any other agent that reads `AGENTS.md` and `.agents/skills/` can follow the workflow, but without a hook nothing stops it before a gate is approved; the check still catches it at commit and in CI.
</Aside>

## Install

<Tabs>
  <TabItem label="npx">
    Run `init` once without installing. The hooks it wires call `lyceum` on every tool call and commit, so also install it globally (any other tab): without it the harness hooks block every tool call and the pre-commit check is skipped.

    ```sh
    npx lyceum init
    ```
  </TabItem>
  <TabItem label="npm">
    ```sh
    npm i -g lyceum
    ```
  </TabItem>
  <TabItem label="Homebrew">
    ```sh
    brew install oritromax/tap/lyceum
    ```
  </TabItem>
  <TabItem label="Go">
    ```sh
    go install github.com/oritromax/lyceum/cmd/lyceum@latest
    ```
  </TabItem>
</Tabs>

Supported platforms are linux-x64, linux-arm64, darwin-x64 and darwin-arm64. Windows isn't supported. See [Install](/start/install/) for release downloads.
